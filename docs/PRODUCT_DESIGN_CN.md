# Allocation Studio · 产品设计说明

## 设计目标

让财务/控制部人员不用先理解 `TOTAL`、`SOURCE`、`AS_IS` 的技术细节，就能回答四个问题：

1. **这笔钱原来在哪里？** 左侧按组织 / 科目 / 来源行展开，能够实际点击选择。
2. **经历了什么分摊？** 中央全阶段链路图，可点击每个步骤理解 Driver 比例及来源。
3. **最终到了哪里？** 结果表按科目过滤，展示商品与金额。
4. **为什么相信结果？** 运行摘要 + 金额池守恒 + 点击行号反查完整血缘。

## 信息架构

- **分摊总览**：业务优先，只显示最关键的数值与链路摘要。
- **计算链路**：清楚说明多因子、多阶段、分叉与合并，折叠底层规则。
- **分摊结果**：表格筛选、源到目标查询、CSV/证据下载。
- **质量检查**：逐池守恒及运行历史。
- **接入指南**：面向非开发者与项目开发者的分步说明。

配色偏深蓝、钴蓝、低饱和青绿；左侧深色导航，主页面浅色信息层，强调可读性，不堆砌炫酷装饰。

## 刻意不做的事情

- 没有把 Web 页面的演示数据当作真实引擎输出；
- 不在前端重写分摊计算；
- 不强行提供完整复杂 DAG 的低代码编辑功能；
- 不要求用户安装 Node、Python、Redis；
- 不允许浏览器上传任意代码然后在服务器执行；
- 不改变原有 Windows / Linux / macOS 计算核心。
