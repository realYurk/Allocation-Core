# 给非开发人员：Allocation Core 怎么用

它是一套**独立计算程序**，不是让你安装 Java 运行环境或 Python 才能做分摊。Windows 上完整解压压缩包，双击 `core/00_Windows_Diagnostic.bat`，再运行 `core/01_Windows_Run_Two_Stage.bat`。

你如果只是想做 2 因子/3 因子/两步骤业务试算，仍然可以用原来的案例与离线试算前端；这次没有改任何计算公式。

这次新增的是生产入口的**容量提示与拦截**：例如要把 3,600 金额池全部分到 50 万个 SKU，磁盘可能需要上 TB。给开发人员一份预算表，程序就能在真正计算前阻止明显危险的运行，但这不是磁盘绝对配额。

想把分摊结果放入 Java 或 Python 工程：**Java 的 JAR 是调用客户端，Go EXE/HTTP 才是计算引擎本体**。项目开发人员负责从本公司的 SQL 读取费用和工时、销量等驱动，调用引擎做一次完整计算，再将有效结果批量导入公司的数据库。

数据库不会一次性把 ledger 全部导入 SQL。常用的业务结果导入现有数据库，详细计算证据放在无损压缩归档里，需要追溯时再读取。

本次所有历史计算模型都保留；不做增量复算、审批或强制 Redis。
