## 尚未达到“生产级公共服务”的地方

1. **单实例文件状态**：本机持久 JSON 元数据，不具备数据库事务、分布式锁、HA 容灾或自动队列恢复。尤其 Windows 文件替换遇到断电时仍有短窗口，暂不宣称严格事务持久化。
2. **HTTP 安全范围**：当前默认本机访问，支持单个 Bearer Token，但不是完整身份鉴权、租户隔离、RBAC/TLS/网关。
3. **资源隔离不足**：请求数量和线程数受限制，但单任务尚无操作系统级 CPU/内存/磁盘配额和外部取消信号。
4. **缓存生命周期**：当前有索引完整性校验与并发构建锁，但没有 LRU、磁盘配额、自动清理、分布式锁。
5. **真实企业性能**：合成数据并不覆盖所有维度组合、数据倾斜、极端负数 Driver 和复杂财务口径；必须引入新公司的样本做验收。
6. **前端与报表**：独立可配置前端仍是参考演示，尚未封装成完整 JavaScript/React/Vue SDK；这次没有将其当作主要交付。
7. **没有审批**：按用户明确要求不做审批，也不自动正式写账。任何正式写回由接入企业实现并校验。

## 风险分级（下一阶段建议）

P0：完整数据库事务任务队列或可靠 append-only 任务日志；可取消任务、分区级磁盘配额/清理；服务安全自检和中途崩溃恢复测试。

P1：多租户隔离、公共 HTTP SDK 和强身份认证；可扩展的结果分页查询/数据库聚合；内存/索引倾斜的压力测试。

P2：前端低耦合 SDK、跨语言的纯原生执行器和平台原生代码生成器。

**不要只凭“百万行在某台测试机上通过”就对客户承诺任何规模、任何规则都能保证某个固定响应时间。**
