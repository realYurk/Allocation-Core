三步接入你已有的项目

不需要重新实现分摊算法，也不需要修改现有核心。

01准备一份规则与数据rule.json + 金额 CSV + Driver CSV，复制到个人数据目录下的 cases/案例名。
02在页面选择案例重新打开工作台，选择新案例，展开科目树并检查各分摊步骤。
03运行并核验结果通过统一计算程序全量计算，下载结果和审计证据，再接现有 SQL / Java。

常见集成方式

Windows 财务人员

双击 AllocationCore.exe → 自动打开浏览器 → 点击运行，不用安装开发环境。

Linux / Mac 开发人员

运行对应平台的 AllocationCore 程序 → 使用浏览器查看案例与任务状态。

Java / Python 业务系统

继续使用原来的 HTTP API 或 CLI；Studio 只是前端配套，不取代现有 SDK。

企业业务数据

放在独立用户数据目录，不打包进软件。规则原文、完整证据和数据仍由现有内核负责。

注意：Studio 是单机本地检查与示例运行工作台，默认只监听 127.0.0.1。它不是多用户企业门户，也不是数据库管理系统。

案例与来源数据

可以直接加载内置双因子、三因子、多步骤和分叉汇合示例。
