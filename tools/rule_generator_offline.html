ALLOCATION CORE / DEVELOPER TOOLS

规则与接入生成器

只生成通用规则与数据模板；真正计算由独立高性能引擎执行。

完全离线 · 无需 Python

1. 定义新公司的维度

维度名称可由公司自己决定；期间、科目、SKU 都不是写死的。使用英文标识更便于系统接口。

2. 设计分摊链路

一行一个维度。AS_IS 表示保留原值，TOTAL 表示将来源金额归集；SOURCE 表示目标维度不变，INCLUDE 表示分给指定成员。支持节点输入的分叉与合并。

3. 生成可迁移规则

下载规则 JSON 后，使用编译好的 Windows EXE 验证、生成 CSV 数据契约与语言接入样例。此工具不直接读取业务库，也不执行正式分摊。

先配置维度与步骤，再点击「检查并生成」。
命令：alloc_windows_amd64.exe generate rule.json 新公司接入包。此命令会生成 Python/Java 适配代码、CSV 模板和双击脚本。执行器文件在完整源码包中。
